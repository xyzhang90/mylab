# MNIST 手写数字识别训练报告

## 一、模型概述

本任务基于 MNIST 数据集（28×28 灰度手写数字图像，0–9 共 10 类），使用 PyTorch 实现了一个全连接神经网络。主要特点如下：

- **输入**：784 维向量（图像展平）
- **网络结构**：5 层线性层，每层后跟 ReLU 激活函数  
  `784 → 128 → 128 → 128 → 64 → 10`
- **损失函数**：交叉熵损失（CrossEntropyLoss）
- **优化器**：随机梯度下降（SGD），学习率 0.1
- **训练轮数**：30 epochs
- **批次大小**：64
- **数据预处理**：  
  - 像素值除以 255 归一化至 [0,1]  
  - 再使用 MNIST 全局统计量标准化：`(x - 0.1307) / 0.3081`

## 五、结果分析与讨论

### 1. 过拟合现象
- 训练准确率 100% 而测试准确率仅 98.32%，存在约 **1.68%** 的差距，表明模型轻微过拟合。
- 主要原因：
  - 模型容量较大（约 150k 参数）而 MNIST 任务相对简单。
  - 缺少正则化手段（Dropout、权重衰减等）。
  - 未使用数据增强。

### 2. GPU 兼容性问题
- 日志中出现警告：RTX 5060 的 CUDA 计算能力（sm_120）不被当前 PyTorch 版本支持，自动回退到 CPU。
- CPU 训练依然可行，但时间稍长（约数分钟）。若需 GPU 加速，可安装支持新架构的 PyTorch nightly 版本或等待官方更新。

### 3. 代码健壮性
- 自定义 `MNISTDataset` 正确处理 CSV 格式数据，并实现了标准化，流程规范。
- 使用了 `torch.no_grad()` 进行测试推理，避免计算梯度，内存友好。

## 六、改进建议

1. **引入正则化**  
   - 在 `nn.Sequential` 中添加 `nn.Dropout(p=0.2)` 层。  
   - 优化器增加 `weight_decay=1e-4` 实现 L2 正则化。

2. **使用更先进的结构**  
   - 替换为卷积神经网络（CNN），通常可达到 99% 以上测试准确率。  
   - 增加批量归一化（BatchNorm）加速收敛并缓解过拟合。

3. **早停机制**  
   - 当验证集准确率不再提升时提前停止训练，避免浪费计算资源。

4. **修复 GPU 支持**  
   - 从 PyTorch 官网获取适合 RTX 5060 的安装命令（预计未来版本会加入 sm_120 支持）。

## 七、结论

本模型成功在 MNIST 数据集上训练并取得了 **98.32%** 的测试准确率，验证了全连接网络对简单图像分类任务的有效性。虽然存在轻微过拟合，但整体性能满足基本识别需求。后续可通过引入卷积结构和正则化进一步提升到 99% 以上。
